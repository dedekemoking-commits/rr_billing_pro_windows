RRBillingClient Warnet v2.3
===========================

Files in this package:
- RRBILLINGCLIENT.exe
- CLIENT_SETUP.bat
- CLIENT_README.txt
- logo.ico

Quick install:
1. Extract the ZIP file.
2. Run CLIENT_SETUP.bat.
3. Open RRBILLINGCLIENT from the desktop shortcut or C:\RRBillingClient\RRBILLINGCLIENT.exe.
4. In Settings, enter the server/kasir IP address and port.
5. Save, then connect.

Notes:
- Recommended default port: 5000
- Client PC and server must be on the same network.
- If Windows Firewall asks, allow the app on Private networks.
