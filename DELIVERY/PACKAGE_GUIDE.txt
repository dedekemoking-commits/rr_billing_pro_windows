🚀 DEPLOYMENT STRATEGY
═════════════════════════════════════════════════════════════════════════════

UNTUK 1 WARNET:
  1. Install ADMIN di 1 komputer (kasir/owner)
  2. Install CLIENT di PC warnet display

UNTUK MULTI WARNET (network):
  1. Install ADMIN di server utama
  2. Install CLIENT di setiap PC warnet
  3. Semua CLIENT auto-connect ke server

CONTOH SETUP:
  Server (Kasir)
    ↓
  RRBillingPro_Admin.exe
    ↓
  Database & Configuration
    ↓
  ← Client 1 (PC Display 1)
  ← Client 2 (PC Display 2)
  ← Client 3 (PC Display 3)
  ← ... (hingga N clients)
