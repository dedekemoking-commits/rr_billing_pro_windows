MENGAPA ADA DIALOG KONFIGURASI DI ADMIN PC?

1. RRBILLINGPRO.exe (Admin Server)

   - Ini adalah SERVER
   - SEHARUSNYA TIDAK ada dialog "Konfigurasi Koneksi Client"
   - Dialog itu adalah BUG

2. RRBILLINGCLIENT.exe (Warnet Client)
   - Jalankan di PC Warnet/Display (192.168.1.9)
   - Ini adalah CLIENT
   - Di sini SEHARUSNYA ada dialog "Konfigurasi Koneksi Client"
   - Di sini user input IP server (192.168.1.17)

MASALAHNYA:
  ❌ Dialog konfigurasi muncul di Admin app (seharusnya tidak ada)
  ❌ Port yang dipakai: 5555 (seharusnya 8888)
  ❌ Koneksi gagal karena salah konfigurasi

🔧 TROUBLESHOOTING - JIKA KONEKSI GAGAL
═════════════════════════════════════════════════════════════════════════════

1. ERROR: "Koneksi ditolak di 192.168.1.17:5555"
   ─────────────────────────────────────────────
   MASALAH: Port salah (5555 bukan 8888)
   SOLUSI:  
   a) Di Client PC, buka RRBILLINGCLIENT.exe
   b) Input port: 8888 (bukan 5555)
   c) Klik "Tes Koneksi"
   d) Harus berhasil

2. ERROR: "Koneksi ditolak" padahal port benar
   ─────────────────────────────────────────────
   MASALAH: Server tidak running atau firewall block
   SOLUSI:
   a) Pastikan Admin PC jalankan RRBILLINGPRO.exe
   b) Cek firewall Windows - allow port 8888
   c) Pastikan kedua PC di network yang sama
   d) Coba ping: ping 192.168.1.17 (di client PC)

3. ERROR: Client tidak bisa connect ke server
   ─────────────────────────────────────────────
   KEMUNGKINAN:
   • IP Address salah
   • Port berbeda
   • Firewall memblokir
   • Network cable not connected
   • WiFi disconnected
   
   SOLUSI:
   a) Check network connectivity
   b) Verify IP addresses correct
   c) Open firewall port 8888
   d) Restart kedua aplikasi

💡 TIPS PENTING
═════════════════════════════════════════════════════════════════════════════

1. Admin app SEHARUSNYA SERVER ONLY
   - Tidak perlu "Konfigurasi Koneksi Client"
   - Dialog itu adalah BUG (perlu diperbaiki di versi berikutnya)

2. Client app SEHARUSNYA CLIENT ONLY
   - Hanya display, tidak bisa edit database
   - Hanya connect ke server

3. Port 8888 adalah standard
   - Jangan ganti ke port lain kecuali ada alasan khusus
   - Pastikan firewall allow port 8888

4. Pertama kali setup:
   - Start Server dulu (Admin PC)
   - Tunggu 2-3 detik
   - Baru start Client (Warnet PC)

5. Network requirement:
   - Kedua PC harus di LAN yang sama
   - IP harus bisa saling ping
   - Port 8888 harus terbuka di firewall
